# Account Book

회사에서 의뢰받아 일하는 개인을 위한 업무 기록 및 일급 입금 관리 웹 서비스입니다.
달력에서 날짜별 업무와 금액을 확인하고, 일급 입금 여부를 관리합니다.

## 주요 기능

- **달력 조회**: 월별 달력에서 날짜별 업무 내용, 금액, 회사명, 근무지를 확인합니다.
- **업무 입력**: 날짜를 선택하고 입력 폼으로 업무 기록을 등록합니다.
- **업무 수정 및 삭제**: 등록한 기록을 수정하거나 삭제합니다.
- **입금 확인**: 업무별 `입금 확인` 버튼을 누르면 상태가 `미입금`에서 `입금 완료`로 변경됩니다.
- **상태 구분**: 달력에서 미입금과 입금 완료 기록을 색상이나 배지로 구분합니다.

## 기록 항목

| 항목 | 설명 |
| --- | --- |
| 근무일 | 실제로 일한 날짜 |
| 업무 내용 | 해당 날짜에 수행한 작업 |
| 일급 | 해당 업무에 대해 받을 금액(원) |
| 회사명 | 업무를 의뢰한 회사 |
| 근무지 | 실제 업무를 수행한 장소 |
| 입금 상태 | 미입금 / 입금 완료 |
| 메모 | 추가로 남길 내용(선택) |

## 기본 사용 흐름

1. 달력에서 근무 날짜를 선택합니다.
2. 입력 폼에 업무 내용, 일급, 회사명, 근무지를 작성하고 저장합니다.
3. 저장한 기록이 해당 날짜에 `미입금` 상태로 표시됩니다.
4. 실제 입금을 확인한 뒤 `입금 확인` 버튼을 누릅니다.
5. 해당 기록이 `입금 완료` 상태로 표시됩니다.

입금 확인은 사용자가 직접 처리하며, 초기 버전에는 은행 계좌 연동을 포함하지 않습니다.

## 기술 구성(예정)

- Python / Django
- SQLite
- Django 템플릿 / HTML / CSS / JavaScript
- 한국어 화면, 한국 시간 기준(`Asia/Seoul`)

## 초기 개발 범위

우선 개인이 사용하는 환경을 기준으로 월별 달력, 업무 입력·수정·삭제, 입금 상태 변경을 구현합니다.
하루에 여러 업무 기록을 등록할 수 있도록 구성합니다.

이후 월별 총 일급·입금액·미입금액 집계, 회사별 조회, 로그인, 엑셀 내보내기를 확장할 수 있습니다.

## 현재 상태

프로젝트 기획 단계입니다. Django 초기 설정과 기능 구현은 아직 진행하지 않았습니다.
설치 및 실행 방법은 기본 환경 구성 후 추가합니다.
