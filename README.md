# Account Book

회사에서 의뢰받아 일하는 개인을 위한 업무 기록 및 일급 입금 관리 웹 서비스입니다.
달력에서 날짜별 업무와 금액을 확인하고, 일급 입금 여부를 관리합니다.

## 주요 기능

- **달력 조회**: 월별 달력에서 날짜별 업무 내용, 금액, 회사명, 근무지를 확인합니다.
- **업무 입력**: 날짜를 선택하고 입력 폼으로 업무 기록을 등록합니다.
- **업무 수정 및 삭제**: 등록한 기록을 수정하거나 삭제합니다.
- **입금 확인**: 업무별 `입금 확인` 버튼을 누르면 상태가 `미입금`에서 `입금 완료`로 변경됩니다.
- **상태 구분**: 달력에서 미입금과 입금 완료 기록을 색상이나 배지로 구분합니다.

## 기록 항목

| 항목 | 설명 |
| --- | --- |
| 근무일 | 실제로 일한 날짜 |
| 업무 내용 | 해당 날짜에 수행한 작업 |
| 일급 | 해당 업무에 대해 받을 금액(원) |
| 회사명 | 업무를 의뢰한 회사 |
| 근무지 | 실제 업무를 수행한 장소 |
| 입금 상태 | 미입금 / 입금 완료 |
| 메모 | 추가로 남길 내용(선택) |

## 기본 사용 흐름

1. 첫 화면의 `ID 만들기`에서 ID, 이름, 전화번호, 생년월일, 비밀번호를 입력해 가입합니다.
2. 로그인 ID, 비밀번호, 생년월일 6자리(YYMMDD)가 모두 일치하면 달력으로 이동합니다. 예: 2000-10-11 → `001011`.
3. 달력에서 근무 날짜를 선택합니다. 상단의 `로그아웃`으로 로그인을 종료할 수 있습니다.

다음 업무 관리 흐름은 추후 구현 예정입니다.

1. 달력에서 근무 날짜를 선택합니다.
2. 입력 폼에 업무 내용, 일급, 회사명, 근무지를 작성하고 저장합니다.
3. 저장한 기록이 해당 날짜에 `미입금` 상태로 표시됩니다.
4. 실제 입금을 확인한 뒤 `입금 확인` 버튼을 누릅니다.
5. 해당 기록이 `입금 완료` 상태로 표시됩니다.

입금 확인은 사용자가 직접 처리하며, 초기 버전에는 은행 계좌 연동을 포함하지 않습니다.

## 기술 구성(예정)

- Python / Django
- SQLite
- Django 템플릿 / HTML / CSS / JavaScript
- 한국어 화면, 한국 시간 기준(`Asia/Seoul`)

## 초기 개발 범위

우선 개인이 사용하는 환경을 기준으로 월별 달력, 업무 입력·수정·삭제, 입금 상태 변경을 구현합니다.
하루에 여러 업무 기록을 등록할 수 있도록 구성합니다.

이후 월별 총 일급·입금액·미입금액 집계, 회사별 조회, 엑셀 내보내기를 확장할 수 있습니다.

## 현재 상태

Django 기반 로그인·회원가입과 월별 달력 화면을 구현했습니다. 로그인 후 달력을 확인할 수 있습니다.
이전·다음 달 이동, 오늘로 이동, 날짜 선택을 지원하며 한국 시간을 기준으로 표시합니다.
업무 등록·수정·삭제와 입금 상태 관리는 아직 구현하지 않았습니다.
비밀번호 찾기 버튼은 준비 중 안내를 표시합니다. 전화번호는 가입 정보로 저장하며 문자 인증은 제공하지 않습니다.
기존 계정에 생년월일이 없으면 정보를 보완하기 전에는 로그인할 수 없습니다.
비밀번호는 해시로 저장하며 Django 세션으로 로그인 상태를 관리합니다.
사용자마다 고유 UUID를 자동 발급하며, 로그인 세션에는 이 UUID를 저장합니다.
기존 로그인 ID와 업무 소유자 연결은 유지합니다. UUID 도입 전 로그인 세션은 다시 로그인해야 합니다.
달력의 선택 날짜에는 로그인한 사용자의 업무 기록만 표시합니다.
GET `/api/work-records/`는 본인 업무 기록만 JSON으로 반환하며, `?date=YYYY-MM-DD`로 날짜를 필터링할 수 있습니다.
요청의 사용자 ID나 UUID는 소유자 선택에 사용하지 않으며, 서버 세션으로 사용자를 결정합니다. 비로그인 요청은 401을 반환합니다.

경로: `/`는 로그인 상태에 따라 `/login/` 또는 `/calendar/`로 이동합니다.
회원가입은 `/signup/`, 로그아웃은 POST `/logout/`입니다.

## 실행

화면 파일은 `front/`에서 관리합니다.

- `front/templates/`: Django가 렌더링하는 HTML 화면
- `front/static/`: CSS, JavaScript, 이미지 등 화면 스타일과 상호작용
- `Back/`: Django 설정, URL, 데이터 처리 및 서버 로직

현재 날짜 선택과 월 이동은 HTML 링크로 서버에 요청하는 방식입니다.
추후 JavaScript를 사용하는 화면 반응도 `front/static/`에 추가합니다.

프로젝트 루트에서 `npm start`를 실행하면 개발 서버와 브라우저가 열립니다.
주소는 `http://127.0.0.1:8000/`입니다. 기존 `.venv`의 Django 환경을 사용합니다.

검증: `.venv\Scripts\python.exe Back/manage.py test worklogs`

DB 변경 적용: `.venv\Scripts\python.exe Back/manage.py migrate`
